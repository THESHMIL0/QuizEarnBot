# Quiz & Earn Auto-Bot (v2.1)

Automated background solver and milestone claimer for Quiz & Earn.

## Features
- Pure OLED Stealth Black theme (zero eye strain, no bright colors).
- 3-Tab Interface: HOME, DATA, and SETTINGS.
- Cloud Auto-Updater: Friends receive new update prompts with optional 1-click update or ignore.
- Comprehensive milestone and bonus rewards claiming across all apps.
- Live stats dashboard tracking daily coins and 25-gem cycles.
