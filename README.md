## 💻 Running on PC (BlueStacks / Emulators)

1. Open **BlueStacks 5** (Recommended resolution: `900x1600` or `1080x1920` Portrait).
2. Enable ADB in **BlueStacks Settings -> Advanced -> Android Debug Bridge**.
3. Drag and drop **[QuizEarnBot.apk](https://github.com/THESHMIL0/QuizEarnBot/raw/main/QuizEarnBot.apk)** into the BlueStacks window to install.
4. Or use the automated PowerShell deployment script:
