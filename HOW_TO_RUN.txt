QUICK SETUP (Takes 30 seconds):

1. BLUESTACKS SETUP:
   - Open BlueStacks 5.
   - Click Settings (Gear Icon) -> Advanced -> Turn ON "Android Debug Bridge (ADB)".
   - Make sure your BlueStacks display is set to Phone (Portrait) mode: 900x1600.

2. RUN THE BOT (Choose either method):

   METHOD A: Windows Desktop Bot
   - Open Quiz & Earn (or CashMafia) inside BlueStacks.
   - Double-click "QuizEarnBot.exe" (or run "Start_Bot.bat").
   - If Windows shows "Windows protected your PC":
     Click "More info" -> Click "Run anyway".

   METHOD B: Native Android APK Bot (Recommended for Multi-Instance)
   - Right-click "deploy_all.ps1" -> "Run with PowerShell".
   - The bot APK will automatically install, grant permissions, and start farming across all connected players!
   - Player 1 (5555) automatically handles Super Offers (downloads & 1,000 coin claims).
   - Secondary players (5585, 5596, etc.) farm gems continuously.

All tools (ADB + DLLs + APK + Scripts) are pre-included. No manual setup needed!
