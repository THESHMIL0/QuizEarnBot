BlueStacks 5 Setup Guide

Configure BlueStacks with modern Android and enable ADB for automated operation.

STEP 01

Create Instance

Open BlueStacks Multi-Instance Manager. Click + Instance → Fresh instance, choose Android 11 or Android 13, assign 4 CPU cores and 4 GB RAM, set resolution to Portrait (900x1600), and click Create.

STEP 02

Enable ADB

Open BlueStacks Settings (gear icon) → select the Advanced tab → toggle Android Debug Bridge (ADB) to ON → click Save changes. BlueStacks will listen on 127.0.0.1:5555.

STEP 03

Run the Automation

Option A (Fastest): Drag and drop QuizEarnBot.apk into BlueStacks, enable Accessibility in Settings, and tap the floating icon.

Option B: Launch QuizEarnBot.exe on Windows; it auto-connects to BlueStacks with status READY.

Frequently Asked Questions

Does the bot stop when it reaches 25 gems?

Yes. Both the Android APK and Windows application track your on-screen gem count and pause execution immediately when 25 gems are reached, giving you time to claim the 1,000 Coins reward.

Can I run the APK inside BlueStacks?

Yes. Drag and drop QuizEarnBot.apk into BlueStacks, enable "Quiz Math Assistant" in Android Settings → Accessibility, and you will get the instant 0.05s solving speed directly on your emulator.

Does the APK require internet or root?

No. The APK has no network permissions in its manifest and requires no root access. It runs entirely through standard Android accessibility APIs.

How does the Windows app update itself?

QuizEarnBot.exe checks version.json on GitHub on launch. If a newer build is detected, it offers a single-click update that swaps the binary while preserving your settings and stats.
