Common Questions

Frequently Asked Questions

Does the downloaded app have the auto-update feature?

Yes! Every user who downloads the app has the built-in Cloud Auto-Updater. When you push a new release to GitHub, their bot automatically detects it on startup and updates itself in 1 click.

Do I need to install .NET or extra software?

No. The bot uses the pre-installed .NET Framework built into Windows 10 & 11, and the portable ZIP bundle includes all required ADB drivers. It has zero registry impact.

Can I run this on my physical Android phone without BlueStacks?

Yes! Turn on "USB Debugging" in your phone's Developer Options and connect via USB (or Wi-Fi). The bot will detect your physical device and run on it automatically. A standalone Android APK is also currently in development!

What happens if BlueStacks crashes while I'm away?

The built-in BlueStacks Watchdog detects the process exit, relaunches BlueStacks automatically, waits for the Android OS to finish booting, reopens Quiz & Earn, and resumes solving and claiming seamlessly.
